# 🚀 NovaFlow – Responsive Landing Page

A modern and responsive **landing page** for a sample productivity platform called **NovaFlow**, built using **HTML and CSS**. The website focuses on clean UI design, responsive layouts, smooth navigation, and a mobile-friendly user experience.

## 🚀 Live Demo

**Live Demo:** https://code-orbit-landing-page-qw586h1vf-t5-6c5f.vercel.app

## 📌 Project Overview

NovaFlow is a responsive productivity platform landing page designed to demonstrate modern frontend web development techniques.

The website includes a responsive navigation bar, hero section, features section, About section, call-to-action section, Contact section, and footer.

The project uses **CSS Flexbox, CSS Grid, Media Queries, hover effects, transitions, and responsive design techniques** to provide a consistent experience across desktop, tablet, and mobile devices.

## ✨ Features

- 🏠 Modern Hero Section
- 🧭 Responsive Navigation Bar
- ☰ Mobile Hamburger Menu
- ⚡ Features Section
- 👤 About Section
- 📢 Call-to-Action Section
- 📞 Contact Section
- 🔗 Footer Navigation
- 🎨 Clean and modern UI
- ✨ Hover effects and transitions
- 📱 Fully responsive design
- 💻 Desktop, tablet, and mobile support
- 📐 Flexbox and CSS Grid layouts
- 🔄 Smooth section navigation
- 🚫 Prevents horizontal overflow on small screens

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and responsive layout
- **CSS Flexbox** – Flexible page layouts
- **CSS Grid** – Responsive card layouts
- **CSS Media Queries** – Responsive design
- **CSS Transitions** – Smooth hover effects
